ℹ️ About this system

An end-to-end automated MLB betting system. Every day around 11 AM ET, GitHub Actions scrapes the day's slate, grades every game across seven categories, anchors the model against Pinnacle's no-vig fair price, and pushes sized recommendations to Discord when (and only when) the edges clear strict gates.

What earns a play onto the card

  • Edge ≥ market floor — 2.5–3.5% depending on market (moneyline 2.5%, total 3%, NRFI 3.5%).
  • Confidence ≥ 6/10 — combines grade gap with edge size. Both axes must contribute.
  • Edge ≤ 12% — anything above this is treated as a calibration bug and rejected.
  • Slate-wide caps — max 5 plays/day, 6 units total exposure, 1 play per game.
  • Plausibility guards — DH 7-inning games and alt-line markets get filtered out.

Signals the model uses

  • Pitching: velocity trend, CSW%, pitch-movement shifts, splits vs handedness
  • Bullpen: recent usage / fatigue + K%/BB%/ERA quality + handedness availability
  • Offense: platoon edges, top-of-order wOBA, 7-day rolling form
  • Weather + park: 10-yr calibrated park factors, wind direction relative to CF, temperature
  • Catcher framing: elite framers boost K projections; soft framers cost expected runs
  • Umpire: live 60-day K-tendency from MLB Stats API
  • Travel: cross-country flights flag the affected offense
  • Market anchor: Pinnacle devigged price is the prior — model only nudges within ±5pp

Honest limits

This is a research and paper-trading system with a real-money layer riding on the same model. All numbers are recommended bets. The CLV tracker (closing-line value) is the only durable short-term proof of edge — win/loss over hundreds of bets is high-variance noise. Past performance does not predict future results.
