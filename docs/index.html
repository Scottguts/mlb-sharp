ℹ️ About this system

An end-to-end automated MLB sharp betting system. Every day at ~11 AM ET, GitHub Actions scrapes the slate, grades every game across 7 categories, anchors the model to Pinnacle's no-vig fair price, and pushes a sized betting card to Discord when (and only when) the edges clear strict gates.

How a play earns its way onto the card

  • Model probability must clear the per-market MIN_EDGE threshold (2.5–3.5%).
  • Confidence must be ≥6/10 — combines grade-gap and edge-size, both axes required.
  • Edge must be ≤12% (anything higher = calibration bug, rejected).
  • Max 5 plays per slate, 6u total exposure, 1 play per game.
  • Plausibility guards filter out misclassified DH games / alt-line markets.

Signals the model uses

  • Pitching: velocity trend, CSW%, pitch movement shifts, splits vs hand
  • Bullpen: usage fatigue + K%/BB%/ERA quality + handedness availability
  • Offense: platoon edges, recent RPG, top-of-order wOBA, 7-day rolling form
  • Weather/park: 10-yr calibrated park factors, wind × CF orientation, temp
  • Catcher framing: elite framers boost K projections, soft framers cost runs
  • Umpire: live 60-day K-tendency from MLB Stats API
  • Travel: cross-country flights flag the offense
  • Market anchor: Pinnacle devigged fair price as Bayesian prior (capped ±5pp)

What it is — and isn't

It is a research / paper-trading system with a real-money betting layer running on the same model. All numbers shown are recommended bets — actual results depend on whether the user placed them. Past performance does not guarantee future results.
